# Support

Thanks for using a Sigilweaver project. Here's how to get help.

## Questions and usage help

- Check the project's README and its documentation site (linked from the
  README badges) first - most projects ship a full reference site.
- For a usage question that isn't answered there, open a GitHub
  Discussion on the relevant repository if it has them enabled, otherwise
  open an issue and label it `question`.

## Bugs

Open an issue using the **Bug report** template. Include the version, your
OS, and a minimal reproduction. See the template for what to share (and
what not to share) about proprietary or sensitive input files.

## Missing format support or features

Use the **Format / feature support request** template.

## Security

Do not open a public issue for a security vulnerability. Each repository
has a `SECURITY.md` with private reporting instructions (GitHub Security
Advisories).

## Response expectations

These are small, single-maintainer projects maintained on a best-effort
basis. Issues and PRs are read, but response times vary. Well-scoped
reports with a reproduction get triaged fastest.
